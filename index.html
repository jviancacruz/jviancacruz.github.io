Projects

Academic Projects

01

BayaniHub

CSR platform for Companies. Software engineering course, team of 5.

A platform that helps a company’s CSR committee find verified NGOs, track monetary, goods and volunteer needs in one place, and keep a record of receipts and cumulative impact. We interviewed stakeholders and possible users which shaped the problem analysis and requirements of the system.

My role
Stakeholder liaison and full-stack contributor. I found and arranged the interviews with the company's HR team and a public school principal, designed the database schema, and built parts of the backend and frontend.
Stack
React on Vercel, Node.js API on Railway, PostgreSQL with Prisma.
Problems solved
Slow discovery of verified NGOs that need help, receipts that may get lost, and separate trackers for monetary, goods and volunteers.

Full walkthrough of the features (~15 minutes)

02

ClassConnect

Classroom Attendance, Support, and Communication Utility

IoT system on ESP32 and AWS. Team of 5.

An ESP32-based system that logs professor attendance through RFID, records audio through a microphone module, and sends the data through Python scripts to AWS S3 and a live web dashboard.

My role
Drafted the network design, led the hardware implementation, and deployed the solution on AWS. Also tested the system around campus.
Problems solved
Unreliable manual attendance checking and slow communication between professors and ITS or security support.
ClassConnect on Facebook

03

Soil Moisture Prediction with an Automated Test Pipeline

Machine learning and CI/CD. Team of 4.

Our team built a Multilayer Perceptron and a Random Forest that predict soil moisture from hyperspectral readings. The focus was reliability and automated testing: Unit tests for all features such as data cleaning, domain splitting, scaling, band selection, both models and the metrics, plus a system test that runs the whole flow on the real dataset, all in an automated pipeline.

My role
Scrum Master. I ran the weekly meetings, tracked what the team had to finish each week, and kept every deliverable moving.
Stack
Python, scikit-learn, PyTorch, pytest.
How it runs
As Python scripts run locally, so there is no hosted demo.
